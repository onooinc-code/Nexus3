# المرحلة الثالثة: الربط بالوقت الفعلي (Phase 3: Real-time with Echo & Reverb)

## نظرة عامة
لا ينبغي على المستخدم أن يقوم بتحديث الصفحة (Refresh) ليرى تقدم المهام. سيقوم خادم Reverb بإرسال التحديثات لتقوم مكونات Vue بالاستجابة.

## المهام (Tasks)
1. **تحديث الـ Backend لإطلاق الأحداث (Events):**
   - إطلاق حدث `TaskStatusUpdated` عند تحديث حالة المهمة في `TaskController`.
   - إطلاق حدث `TaskLogAdded` عند كتابة سجل جديد من الوكيل.
2. **الاستماع في Vue (Echo Listeners):**
   - في مكون `TasksKanban.vue`، الاستماع لقناة المهام العامة:
     `Echo.channel('tasks').listen('TaskStatusUpdated', (e) => { // تحديث الكانبان })`
   - في مكون `LiveLogViewer.vue`، الاستماع للقناة الخاصة بالمهمة:
     `Echo.private('task.' + taskId).listen('TaskLogAdded', (e) => { // إضافة سطر اللوج مع التمرير لأسفل })`
3. **تحديث شريط الحالة (Queue Stats):**
   - بناء مكون Vue صغير في أعلى الكانبان للاستماع لتحديثات صحة الطابور وإعادة طلب الـ API أو الاعتماد على بيانات البث المباشر.
