⚡ الهندسة المعمارية لـ NexusV3

لماذا لا يوجد ملف بسيط اسمه AiPromptBuilder.php؟

في النظم التفاعلية فائقة التطور مثل NexusV3، بناء التلقين (Prompt Engineering) ليس مجرد ربط سلسلتين نصيتين معاً! لو اعتمدنا على فئة واحدة بسيطة، لحدث انهيار في أداء النماذج وتداخل بين شخصيات الوكلاء وميزانية الـ Tokens. لذلك تم تقسيم وظيفة "بناء التلقين" إلى 4 محركات متخصصة (4 Specialized Pipelines) تعمل بتناغم مطلق وتتكامل مع الـ 15 Hubs المعتمدة في النظام.

1. خط تجميع السياق العام

Pipeline

ContextAssemblyPipeline.php

المتعهد الرسمي بتوليد الـ Prompts لمهام التوجيه العام والاتصال بالخدمات. يقوم بدمج أحدث 10 ذكريات (Memories) من قاعدة البيانات الدلالية، وأحدث 20 رسالة من أرشيف المحادثة، ويرصعها في قالب Markdown منظم للغاية.

الدوال المحورية: assemble() ➔ buildPrompt()

2. مٌجَمِّع سياق النواة الإدراكية

Hedra Soul

SoulyContextAssembler.php

القلب النابض للمستشار الذكي (Souly). لا يكتفي بالتجميع بل يطبق خوارزمية **إدارة ميزانية الـ Tokens (حد أقصى 8000 Token)**، يقلم الرسائل بذكاء إذا زاد الحجم، ويحقن حقائق الملف الشخصي (Profile Facts) ويصنف المخاطر الأمنية للحوار.

الحماية: Risk Classifier (Low / Med / High)
TOKEN_BUDGET = 8000

3. محرك تخصيص النبرة والشخصية

System Prompt

PersonaToneEngine.php

المسؤول الحصري عن إنشاء التوجيه السلوكّي (System Prompt). يفحص شخصية المستفيد (Contact) ويُفصّل التوجيه حسب قوالب متخصصة: مهني (Default)، خبير (Expert)، حميم ودود (Friendly)، موجز (Concise)، أو عاطفي متفهم (Empathetic).

الوظيفة الأساسية: buildSystemPrompt()

4. مهندس التلقين لوكيل المتصفح

ReAct Engine

ReActAgentEngine.php

المصمم العبقري لتلقين إضافة الكروم (Ertugrul Extension). يُلزم النموذج بالرد بنسق JSON متجانس لإنتاج دورة (Thought ➔ Plan ➔ Action ➔ Observation). يحقن قائمة المهام الحية ويمنع التكرار اللانهائي بحدود 15 خطوة.

الاتصال الفوري: يعمل عبر بوابة LiteLLM (Gemini 3.5 Flash)

مراحل فلترة وبناء الـ Prompt (خطوة بخطوة):

1

استجواب التفضيلات والنبرة (Tone & Persona Extraction)

عند انطلاق الحدث، يراجع الخادم هل لدى العميل (Contact) تفضيل مسبق لشخصية معينة. يتم استخدام دالة buildSystemPrompt() لصهر التوجيه الأساسي للنموذج لضبط سلوكه.

2

الاستحواذ على الذاكرة الدلالية (Vector Memory & History)

عبر ContextAssemblyPipeline يتم حقن السياق بقالب Markdown مقسم. هذا يمنح النموذج قدرة خرافية على تذكر المحادثات القديمة دون إرباك مسار السؤال الحالي.

3

الحكامة والتقليم الأمني (Token Budgeting & Risk Audit)

يتولى SoulyContextAssembler حساب التكلفة (Token Estimate) بالوقت الحقيقي. لو تجاوز السياق 8000 Token، يتم قص الرسائل القديمة وحظرها بذكاء مع تسجيل تصنيف الأمان (Low/High) وحفظه في جدول hedrasoul_context_snapshots.

1. المحرك العام

ContextAssemblyPipeline

app/Services/Pipelines/ContextAssemblyPipeline.php

صُمّم هذا الكائن ليكون مجمعاً نظيفاً (Clean Assembler) يعتمد على تمرير البيانات عبر 3 قنوات أساسية:

  • loadMemories(): جلب استنتاجات الذكاء الاصطناعي السابقة عن جهة الاتصال.
  • loadHistory(): فرز الرسائل ترتيباً تصاعدياً ليفهم النموذج التسلسل الزمني.
  • buildPrompt(): تجميع كل العناصر في سلسلة Markdown موحدة.

public function buildPrompt(array $context, string $userMessage): string
{
    $parts = [];

    // 1. إدراج الذكريات التلقائية إن وجدت
    if (! empty($context['summary'])) {
        $parts[] = "## Relevant Context\n" . $context['summary'];
    }

    // 2. رصف أرشيف المحادثة السلس
    if (! empty($context['history'])) {
        $parts[] = '## Conversation History';
        foreach ($context['history'] as $msg) {
            $role = $msg->sender_type === 'user' ? 'User' : 'Assistant';
            $parts[] = "{$role}: " . $msg->content;
        }
    }

    // 3. إضافة رسالة المستخدم الجديدة في الذيل
    $parts[] = "## Current Message\n" . $userMessage;

    return implode("\n\n", $parts);
}
2. العقل الإدراكي

SoulyContextAssembler

app/Services/HedraSoul/SoulyContextAssembler.php

هذا الكلاس يمثل قمة الهندسة الأمنية في التلقين. يدير ميزانية الـ Tokens لمنع الانفجار السعري عند الاستدعاءات الخارجية.

تقييم المخاطر (Risk Audit): يمنع الوكيل من إرسال رسائل خارجية عبر الواتساب (WAHA) إذا كان التلقين يحتوي على إشارات (Mentions) مجهولة، حمايةً للمعلومات من التسريب! 

const TOKEN_BUDGET = 8000; // حد الميزانية الصارم

// التقدير التقريبي للحجم: 1 Token ≈ 4 Characters
$jsonPayload = json_encode($payload);
$tokenEstimate = strlen($jsonPayload) / 4;

// لو تم تخطي الميزانية، اقتطع القديم للحفاظ على كفاءة الخصومة
if ($tokenEstimate > self::TOKEN_BUDGET) {
    $payload['recent_messages'] = array_slice($payload['recent_messages'], -10);
    $excludedItems[] = [
        'key' => 'older_messages',
        'reason' => 'Exceeded token budget (limit: 8000)',
    ];
}

// حساب الخطورة الأمنية للـ Prompt قبل الإرسال
$risk = 'low';
if ($payload['external_messaging_access'] && !empty($payload['mentions'])) {
    $risk = 'high'; // حماية ضد التسريب الخارجي عبر WAHA
}

protected function buildSystemPrompt(array $config): string
{
    $parts = [
        "You are a ".$config['name']." assistant.",
        $config['description'],
        'Traits: '.implode(', ', $config['traits']),
    ];
    return implode(' ', $parts);
}
