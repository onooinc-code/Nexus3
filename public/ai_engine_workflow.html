📋 Detailed Scenario Case Breakdown

Case 1: Standalone Request (Success) Primary Ready

User sends prompt directly to single agent. DynamicRestProvider resolves encrypted API key for Priority #1 provider (e.g. AIStudio Proxy or DeepSeek), fires HTTP POST, logs tokens in usage_logs, and renders response in HedraSoul chat pane.

Case 2: Primary 429 Failover Auto Failover

Priority #1 returns 429 Rate Limit. System logs health metric in provider_health_metrics, sets temporary rate_limit_reset_at timestamp, and automatically routes request to Priority #2 provider without user intervention.

Case 3: Sequential Agent Chain Agent A ➔ Agent B

Prompt is fed to Agent A. Output of Agent A is automatically sanitized and injected as context input for Agent B. Both steps log token counts independently in analytics.

Case 4: All Providers Offline Graceful Error

If every configured provider fails, system intercepts final exception and returns structured JSON error specifying retry duration and status details.
