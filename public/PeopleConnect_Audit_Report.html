2. What is PeopleConnect? (Executive Summary)

PeopleConnect is the central cognitive communication engine in NexusV3. It unifies live external messaging via WhatsApp (powered by the WAHA Engine) with a zero-latency real-time frontend (Cloud Firestore + Reverb) and autonomous AI conversational agents. It essentially acts as a multi-channel Command Center where human operators and AI work simultaneously to handle inbound customer interactions.

3. Core Features

⚡ Hybrid Zero-Latency UI

Combines MySQL Server-Side Rendering (SSR) for instant first-paint loads with Firebase Cloud Firestore for real-time WebSocket DOM updates, guaranteeing zero lag without browser refreshes.

🤖 AI Autopilot & Fallback

Supports Manual, Assisted (AI writes drafts for approval), and Autopilot modes. Incorporates a 3-tier sequential fallback hierarchy (OpenAI → Gemini → Anthropic/Groq) to ensure 99.9% uptime during API outages.

🔑 Multi-Key Rotation Engine

Enterprise encryption for API keys at rest. If a key hits rate limits, the system automatically tags it for a cooldown period and rotates to the next available, healthy encrypted key in the pool.

🛡️ Security & Idempotency

Incoming WhatsApp webhooks are verified via HMAC SHA-256 signatures. Advanced deduplication prevents double-processing of identical messages during burst messaging.

4. System Workflows (How the Code Works Today)

📥 Inbound Webhook Pipeline

1
Ingestion & Validation: WAHA posts to WebhookController. HMAC signature is verified. WahaWebhookIngestionService deduplicates payloads and saves raw JSON to DB.
2
Background Resolution: ProcessWahaWebhookJob starts. Uses Redis locks to resolve the Contact. Validates a 2-Hour Sliding Window session via PeopleConnectSessionService.
3
Persistence & Broadcast: The message is saved via PeopleConnectMessageService. FirestoreSyncService pushes updates to Firebase, while PeopleConnectRealtimeBroadcaster pushes Laravel Reverb WebSocket events to the frontend.

🧠 AI Cognitive Reply Pipeline

1
Context Assembly: After ingestion, AnalyzePeopleConnectMessageJob triggers. PeopleConnectContextAssembler collects history and creates a strict max 8,000-token contextual snapshot.
2
Mode Evaluation: PeopleConnectReplyModeService determines if the chat is Manual, Assisted, or Autopilot, while enforcing a strict 5 messages / 5 minute velocity safety limit.
3
Agent Orchestration: PeopleConnectAgentReplyService pings the Nexus AgentsHub. Depending on the mode, it either persists a PeopleConnectReplyDraft for human approval, or instantly transmits it back to WAHA.

📤 Outbound Dispatch Pipeline

1
HTTP Transmission: Whether manual or Autopilot, outbound texts route through DispatchWahaMessageJob and WahaMessageDispatcher, which execute an HTTP POST to WAHA's /api/sendText.
2
Delivery Auditing: The HTTP response latency and delivery status are instantly recorded into peopleconnect_delivery_attempts for complete diagnostic visibility.
