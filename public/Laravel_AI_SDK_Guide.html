مرجع وموسوعة Laravel AI SDK

الدليل التفاعلي الشامل لجميع الواجهات (Interfaces)، الفئات (Classes)، الدوال (Methods)، الـ Attributes، والـ Traits الخاصة بالحزمة الرسمية الأولى للذكاء الاصطناعي من Laravel.

التوفير والجاهزية (Failover & Routing)

تدعم الحزمة خاصية **Failover** التلقائية، بحيث إذا توقف أحد المزودين (مثل OpenAI)، يتم التحويل أوتوماتيكياً للمزود الاحتياطي (مثل Anthropic):

$response = (new MyAgent)->prompt( 'Hello', provider: [Lab::OpenAI, Lab::Anthropic] );

المزود المخصص (OpenAI-Compatible)

يمكنك توجيه الـ SDK لأي سيرفر يعمل بنمط OpenAI (مثل LM Studio أو Ollama أو السيرفر الخاص بنا في Nexus):

// في config/ai.php 'my-llm' => [ 'driver' => 'openai-compatible', 'url' => env('MY_LLM_URL'), 'key' => env('MY_LLM_KEY'), ]

أمثلة برمجية شاملة (Full Usage Code)

1. بناء Agent متكامل مع Tools و Attributes و Structured JSON

namespace App\Ai\Agents; use Laravel\Ai\Contracts\{Agent, HasTools, HasStructuredOutput}; use Laravel\Ai\Promptable; use Laravel\Ai\Attributes\{Provider, Model, Temperature, MaxTokens}; use Laravel\Ai\Enums\Lab; use Illuminate\Contracts\JsonSchema\JsonSchema; #[Provider(Lab::Gemini)] #[Model('gemini-1.5-pro')] #[Temperature(0.2)] #[MaxTokens(2000)] class ServerMonitorAgent implements Agent, HasTools, HasStructuredOutput { use Promptable; public function instructions(): string { return 'You are a Linux Server Monitor Agent.'; } public function tools(): iterable { return [new CheckDiskSpaceTool, new RestartNginxTool]; } public function schema(JsonSchema $schema): array { return [ 'status' => $schema->string()->enum(['ok', 'warning', 'critical']), 'report' => $schema->string(), ]; } }

2. البث المباشر (Streaming) والمعالجة في الخلفية (Queueing)

// 1. Streaming (إرجاع SSE Stream للمتصفح مباشرة في الـ Controller) return (new ServerMonitorAgent)->stream('افحص السيرفر'); // 2. Queueing (تشغيل الـ Agent في الخفاء عبر Laravel Worker) (new ServerMonitorAgent) ->queue('افحص السيرفر') ->then(fn ($response) => Log::info($response->text));

اختبار ومحاكاة الـ AI (Testing & Faking)

توفر الحزمة إمكانية عمل `fake()` لجميع المكونات لمنع استهلاك API Keys الحقيقية أثناء كتابة الـ PHPUnit / Feature Tests:

اختبار الـ Agents

// محاكاة ردود الـ Agent SalesCoach::fake(['رد وهمي تجريبي']); // تنفيذ الكود المطلوب فترته $response = (new SalesCoach)->prompt('سؤال'); // التأكد من أن الـ Prompt تم إرساله SalesCoach::assertPrompted('سؤال'); SalesCoach::assertNotPrompted('سؤال آخر'); SalesCoach::fake()->preventStrayPrompts();

اختبار الميديا والمستندات

// محاكاة الصور والصوت Image::fake(); Audio::fake(); // التأكد من إنشاء الصورة بخصائص معينة Image::assertGenerated(fn ($p) => $p->contains('sunset')); // محاكاة الـ Vector Stores Stores::fake(); Stores::assertCreated('قاعدة معرفة نكسس');
