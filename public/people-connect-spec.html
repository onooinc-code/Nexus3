الشروط والمتطلبات الأساسية للنظام

1. ملف شخصي شامل (Single Source of Truth)

إنشاء هيكل بيانات موحد في Nexus لكل جهة اتصال يتضمن: الحقائق المؤكدة، تاريخ الرسائل السابقة، المواضيع المشتركة، مواصفات وشخصية الشخص، مواقفه ومبادئه، بالإضافة إلى ملاحظات وتنبيهات هدرا الخاصة بهذه الشخصية.

2. تحليل الشخصية والمواقف والمبادئ

تحديد وتصنيف شامل لكل ما يفيد في فهم شخصية جهة الاتصال: نمط الحديث، المواقف السابقة، الحدود والمبادئ التي يتعامل بها هدرا معه، ودرجة القرب (عائلية، عمل، شخصية، رسمية، إلخ).

3. نظام مهام خاص بالتواصل (Dialogue Task Engine)

نظام إدارة مهام متطور يختلف عن المهام العادية، حيث يعتمد على طبيعة وسياق المحادثات والهدف المطلوب الوصول إليه (Goal-Driven Dynamic Dialogue) مع تحديث واستقبال التفاصيل لحظياً.

4. قنوات وتدفقات التواصل (WhatsApp & FB)

التواصل سواء ببدء محادثات صادرة لتحقيق هدف محدد مع شخص معين (Outgoing Goal Chat)، أو استقبال المحادثات الواردة وتوجيه الحديث نحو تحقيق الهدف (Incoming Goal Handler) عبر WAHA و Meta Graph API.

هيكل جداول قاعدة البيانات في Nexus 3

CREATE TABLE contact_profiles ( id UUID PRIMARY KEY, full_name VARCHAR(255) NOT NULL, relationship_tier VARCHAR(50), -- family, close_friend, business, formal, toxic phone_number VARCHAR(50), facebook_id VARCHAR(100), avatar_url TEXT, summary_bio TEXT, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); CREATE TABLE contact_facts ( id UUID PRIMARY KEY, contact_id UUID REFERENCES contact_profiles(id), category VARCHAR(50), -- personality, work, stances, habits, warnings fact_key VARCHAR(100), fact_value TEXT, confidence_score FLOAT DEFAULT 1.0, source_origin VARCHAR(100) -- whatsapp_archive, fb_chat, fb_xml, hedra_manual ); CREATE TABLE contact_stances_principles ( id UUID PRIMARY KEY, contact_id UUID REFERENCES contact_profiles(id), topic VARCHAR(100), hedra_stance TEXT NOT NULL, strict_boundary_rules TEXT, past_incidents TEXT ); CREATE TABLE dialogue_tasks ( id UUID PRIMARY KEY, contact_id UUID REFERENCES contact_profiles(id), goal_type VARCHAR(50), -- outgoing_target, incoming_handler, relationship_nurture target_outcome TEXT, current_state VARCHAR(50) DEFAULT 'initiated', -- initiated, in_progress, goal_satisfied, escalated last_message_at TIMESTAMP, requires_hedra_approval BOOLEAN DEFAULT FALSE ); CREATE TABLE message_history ( id UUID PRIMARY KEY, contact_id UUID REFERENCES contact_profiles(id), platform VARCHAR(30), -- whatsapp, messenger sender VARCHAR(20), -- hedra_twin, contact, hedra_human message_text TEXT, sentiment VARCHAR(20), timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP );
