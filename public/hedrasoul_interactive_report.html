Interactive Codebase & Route Matrix

GET HedraSoulSessionController
/api/hedrasoul/sessions

Retrieves active conversational sessions sorted by latest activity with task counts.

POST HedraSoulSessionController
/api/hedrasoul/sessions/{session}/messages

Submits user instruction, triggers SoulyContextAssembler, queues AI reply job.

PATCH SoulyControlController
/api/hedrasoul/souly/autonomy

Updates Souly autonomy level (chat_only, copilot, operator, autopilot).

POST SoulyControlController
/api/hedrasoul/souly/quarantine

Emergency lockdown trigger for Souly AI. Instantly pauses background command execution.

POST SoulyInstructionController
/api/hedrasoul/instructions/{v}/activate

Activates a specific system prompt version and updates active instructions globally.

POST HedraMemoryController
/api/hedrasoul/memory-maintenance

Triggers decay calculation, deduplication check, and embedding vector recomputations.

POST HedraSoulApprovalController
/api/hedrasoul/approvals/{id}/approve

Approves a pending high/medium risk action request submitted by an autonomous agent.

GET HedraSoulNotificationController
/api/hedrasoul/notifications

Lists active system notifications and pending human approval alerts for mobile/web UI.

Comprehensive HedraSoul UI/UX Improvement Proposals

Actionable design and functional suggestions to upgrade HedraSoul into a world-class AI Command Center.

1. Grid-Canvas Hybrid Workspace

High Impact
  • Gridstack.js 12-Column Layout: Enable user to drag, drop, minimize, and dock widgets into floating quick-action buttons.
  • Figma-like Dot Grid Canvas Mode: Toggle with 1 click between standard grid layout and infinite scrollable dot-canvas (`scale 70%` to `150%`).
  • Dynamic Neon Mood Aura: Update top mood indicator bar dynamically based on system state:
    • • Focus Mode: Purple glow (`#8b5cf6`) for deep programming.
    • • Planning Mode: Blue glow (`#3b82f6`) for requirements and roadmaps.
    • • Critical Mode: Red glow (`#f43f5e`) for emergency alerts & failed queues.
    • • Empathy Mode: Emerald glow (`#10b981`) for casual chat & mental break.

2. Interactive Reasoning & Context Gauge

High Impact
  • SoulyActionTrace Expander: Render collapsible step-by-step reasoning steps (`Thinking...` → `Searching file X` → `Validating syntax`) inside chat bubbles.
  • Live Context Token Bar: Display real-time token count meter (e.g. `4,210 / 8,000 tokens`) driven by `SoulyContextAssembler` with visual warning before auto-snapshotting.
  • Inline Code Action Cards: Code blocks generated in chat should feature a 1-click "Apply to Codebase" button that fires backend file updates directly.
  • Multi-Agent Debate Renderer: When multi-agent debate mode is triggered, render response as side-by-side agent avatars (e.g. Architect vs Security Reviewer).

3. Human-in-the-Loop Approval Drawer

Critical Safety
  • Emergency Stop Switch: Top header button to instantly halt all running background jobs and put Souly into Quarantine mode.
  • Risk-Leveled Approvals Drawer: Slide-over drawer surfacing pending `HedrasoulApprovalRequest` items color-coded by risk:
    • • HIGH RISK (Red): Database drop, file deletion, server reboot.
    • • MEDIUM RISK (Yellow): Package install, API key modification.
    • • LOW RISK (Green): File read, test execution (auto-approved in Operator mode).
  • Instant Autonomy Mode Switcher: Quick toggle dropdown in right sidebar for switching modes seamlessly.

4. Memory Constellation & Clone Manager

Core Feature
  • Visual Memory Node Graph: Interactive canvas mapping active memories with confidence sliders (0.0 to 1.0) and decay status.
  • Hedra Profile Facts Manager: Inline editor to view, edit, or delete personal preferences and system conventions.
  • Clone Source Upload UI: Drag-and-drop file/chat ingest box for fine-tuning Hedra's AI clone profile.
  • 1-Click Memory Maintenance: Button to trigger deduplication and vector re-embedding manually with feedback log.
