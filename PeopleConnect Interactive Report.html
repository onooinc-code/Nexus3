 Echo Event Listeners (JavaScript)

                            
When Echo receives events, Javascript inserts message cells and updates counters dynamically.

                            
Echo.private(`peopleconnect.conversation.${conversationId}`)
    .listen('.message.received', (e) => {
        // 1. Append message to chat panel
        appendMessageBubble(e.body, e.direction);
        // 2. Play alert notification sound
        playNotificationAudio();
    })
    .listen('.message.analyzed', (e) => {
        // Update sentiment & intent labels dynamically in active thread header
        updateSentimentIndicator(e.sentiment, e.intent);
    });
